# Gwen Stacy Spider-Verse

Aplicacion web desarrollada con Web Components, Lit, Vite y @vaadin/router.

El proyecto presenta una galeria inspirada en Gwen Stacy y Miles Morales, con rutas limpias, componentes reutilizables y formularios funcionales.

## Tecnologias

- Lit
- Vite
- @vaadin/router
- Web Components
- JavaScript
- CSS

## Instalacion

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

Luego abrir:

```text
http://localhost:5173
```

## Compilar

```bash
npm run build
```

## Rutas

- `/` Inicio
- `/gallery` Galeria
- `/direction` Direccion y contacto
- `/formulario` Formulario Spider-Verse
- `/equipo` Equipo Spider-Verse
